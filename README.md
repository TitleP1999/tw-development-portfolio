# TW Development Portfolio

Next.js + TypeScript + Tailwind CSS portfolio/landing page.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Deploy to Vercel

1. Create a GitHub repository.
2. Push this project to GitHub.
3. Import the repository in Vercel.
4. Vercel will detect Next.js automatically.
5. Click Deploy.

## Before publishing

- Replace demo Portfolio cards with real/demo projects you want customers to see.
- Update the brand name if you decide on a final team name.
- Add Facebook/Messenger URL once the Page username is finalized.
- Do not publish confidential code, client names, internal URLs, credentials, or company screenshots without permission.
